# 玄鉴仙族文风润色

根据季越人《玄鉴仙族》的文风特点，对给定的小说章节进行润色改写。**默认执行重度改写**，除非用户明确指定轻度或中度。

## 润色强度档位

执行前，先确认用户想要的强度（未指定则默认**重度**）：

| 强度 | 做的事 | 不改的事 |
|------|--------|----------|
| **轻度** | 标点规范（『』【】''  ""  …  ——）、称谓按等级修正、心理描写单引号 | 句式结构、段落组织、描写篇幅 |
| **中度** | 轻度所有项 + 句式节奏（短句化、逗号分隔）、对话风格（雅俗分级）、环境氛围增强 | 段落结构、情节顺序 |
| **重度（默认）** | 中度所有项 + 段落重组、描写增补、场景氛围重铸、对话重构 | 人物姓名、核心设定、关键情节信息 |

## 执行流程

必须严格按照以下 4 步执行，不可省略：

### 第一步：读原文 → 识别
识别并列出：
- **场景类型**：战斗 / 修炼悟道 / 政治博弈 / 市井生活 / 书信玉简 / 坊市交易 / 日常过渡
- **在场人物及其身份**：上位者 / 平辈 / 下位者 / 凡人，确定每人应使用的称谓和语体
- **核心情节节点**：不可改变的关键事件和对话信息

### 第二步：定策略
用 3-5 句话说明本轮润色将做哪些调整：
- 称谓如何替换
- 标点如何转换
- 句式如何调整
- 需要增补什么（环境、动作、心理）

### 第三步：逐段改写
按文风规则逐段润色输出。重要段落前面标注 `【场景：XX】`。

### 第四步：自校验
输出润色稿后，逐项对照检查：
- [ ] 『』【】标点规范
- [ ] 心理描写用单引号 `'...'`
- [ ] 对话占比 ≥ 50%
- [ ] 称谓符合人物身份等级
- [ ] 短句为主（单句 ≤ 30 字）
- [ ] 未改变核心情节信息
- [ ] 无凡人角色说修炼术语
- [ ] 四字词组使用恰当不过度
- [ ] 天地异象与事件级别匹配

## 文风核心特征

### 一、语言风格：半文半白，古典与市井交融

**1. 对话兼用雅俗**

上位者（老祖、峰主、真君）：含蓄典雅，留有余韵。
> ❌ "我觉得这样做不太好。"
> ✅ "此事……恐有不妥。"

平辈修士：半文半白，直率有节制。
> ❌ "你疯了吧，这怎么可能成功？"
> ✅ "你……当真想好了？此路可不好走。"

底层/凡人：直白粗犷，偶带脏话。
> ❌ "这地方太危险了，我不敢去。"
> ✅ "他娘的，那地方谁敢去？"

**2. 称谓讲究等级**

| 身份 | 自称 | 他称（上→下） | 他称（下→上） |
|------|------|--------------|--------------|
| 老祖/真君 | 老夫、本座 | 直呼其名或"你这小辈" | 老祖、真君、前辈 |
| 峰主/金丹 | 我、本座 | 道号/姓氏+道友 | 峰主、前辈、上使 |
| 筑基弟子 | 我、弟子 | 师弟/师妹 | 师兄/师姐、师叔、峰主 |
| 胎息/练气 | 弟子、小人 | 师兄弟 | 师兄、师叔、长老 |
| 凡人 | 小人、草民 | 直呼 | 仙师、上使、大人 |

**3. 四字词语密集但自然**

用于状物、写景、描摹情态，不堆砌到影响阅读。
> 常用的：深不可测、栩栩如生、顶礼膜拜、心念旧情、古井无波、寂然无声、瞬息之间、须臾之间、隐隐约约、若有若无

### 二、叙事结构：对话驱动，心理穿插

**1. 对话主导叙事**

情节推进以人物对话为主，占比 **50%–70%**。对话之间穿插简短动作描写和心理活动，形成"**说—动—思**"交替节奏。

**2. 心理描写标注**

- 单引号包裹内心独白：`'自炼我金！'`、`'未免太小看了我成道的决心。'`
- 引导词+双引号：心中暗道："……"、暗暗思量："……"

> ❌ 他觉得这个计划很危险，但又不甘心放弃。
> ✅ 他默然良久，'此计虽险……却是我唯一的机会了。'

**3. 动作—反应链**

每个行动必有反应——"XX见了，顿时XX，XX道："模式频繁使用。人物之间互动有来有回，步步推进。

> ❌ 他说了一句狠话。对方很生气，拔出了剑。
> ✅ 他冷笑一声："你当真以为我怕了你？"对面那人面色一沉，手已按上剑柄，却未出鞘，只森然道："你再说一遍。"

### 三、环境描写：以景写情，意象厚重

**1. 环境服务于心境**

天气、光线、声音与人物的命运和情感同步。
> 李通崖坐化时——"好难得一阵秋雨"
> 萧初庭陨落时——"灰飞烟灭"

**2. 天地异象分级匹配**

| 事件级别 | 气象规模 | 示例 |
|----------|----------|------|
| 金丹突破/陨落 | 天地变色、雷霆翻涌、灵机震荡 | "一时间天昏地暗，雷霆自九天劈落" |
| 紫府突破 | 方圆百里灵机翻涌、风云汇聚 | "灵机如潮，自四方涌来" |
| 筑基突破 | 周身数丈气机波动、微风拂过 | "周身气机微微一荡" |
| 低级别战斗 | 无天地异象，仅局部光影 | "剑光一闪" |

**3. 市井细节穿插**

在宏大叙事中穿插市井细节，形成反差和节奏变化。
> 黄犬低吠、孩童嬉笑、小贩撑伞、老妪倚门、炊烟袅袅、鸡鸣犬吠

### 四、句式与节奏

**1. 短句为主，逗号密集**

单句 10–25 字为主，不超过 30 字。逗号频繁使用形成流畅叙述节奏。

**2. 三字/四字节奏组交替**

> "只见那，云海翻涌，天光乍泄，一道金芒，自东方而来。"

**3. 排比递进（关键时刻使用）**

> "是五百年的修行，是无数次行走于刀锋，是——险之又险！"

**4. 省略号用于停顿**

对话中使用 `…` 表示停顿、迟疑、语气转折。禁止用 `......` 或过多惊叹号。

### 五、特殊标点与格式

| 符号 | 用途 | 示例 |
|------|------|------|
| `『』` | 功法名、神通名、地名、道号、宗门名 | `『长云暗』`、`『位从险』`、`『浩瀚海』`、`『青池宗』` |
| `【】` | 特殊物品、秘境、阵法名、丹药名 | `【神雷玄音鼓】`、`【在窞溪】`、`【青革天】` |
| `""` | 人物对话（主要） | `"我乃青池宗青穗峰主。"` |
| `''` | 内心独白、暗语、腹诽 | `'自炼我金！'` |
| `──` | 场景分隔（单独成行） | 用于段落之间的场景转换 |
| `…` | 语气停顿 | `"老祖！您……好了？！"` |
| `——` | 强调、转折或插入说明 | `"无穷无尽的——妖魔！"` |

**标点转换规则**：
- 原作的 `「」` → `""`（对话）
- 原作的 `『』` → 保留用于功法/神通/地名/道号
- 心理活动 → `'...'`
- 作品名/书目 → `《》`

### 六、人物塑造

**1. 称谓多变**

同一人物在不同视角/场合下用不同称谓（姓名、字号、身份、外貌特征）：
> 李通崖可被称为"李通崖"、"通崖"、"老祖"、"白衣少年"、"那少年"

**2. 情感克制**

不写大哭大闹。通过细节动作传递情感：
> 两眼微红、神色肃穆、默然良久、嘴角微动、袖中拳头紧握、指尖微颤

**3. 人物出场有"亮相"**

新人物登场伴随外貌、气质的简练描写，不超 30 字：
> "一袭黑衣，面容俊朗，棱角分明，目若朗星"
> "身着灰袍，须发皆白，目光如电"

### 七、战斗与修炼描写

**1. 修炼境界层次**

胎息 → 筑基 → 紫府 → 金丹 → 真君，每层有独特气象。

**2. 法术描写重意象，不数据化**

> ❌ "他释放了 3000 点灵力的天雷术，造成了 5000 伤害。"
> ✅ "他抬手一指，雷光自指尖迸发，幽蓝的光彩汇聚一线，轰然劈落。"

**3. 战斗节奏快**

对决在几个关键动作中分出胜负，不写冗长回合。
> "两人交手不过三合，那人便倒退数步，面色发白。"

## 场景专项规则

### 场景一：政治博弈

- 对话占比更高（70%+），话中有话，留白多
- 大量使用"默然"、"良久"、"微微一笑"、"神色不变"
- 情绪完全内敛，不直接写心理活动，靠细微动作暗示
- 称谓严格遵守等级，一言一行体现尊卑秩序

### 场景二：市井生活

- 对话接地气，可使用"他娘的"、"够呛"、"这小崽子"等口语
- 穿插生活化细节：炊烟、犬吠、孩童、摊贩、油纸伞
- 不使用修炼术语（除非修士混迹市井）
- 节奏放慢，可有闲笔

### 场景三：书信/玉简传讯

- 书信内容用引文格式，语气文雅
- 开头常有："敬启者……"、"某谨呈……"
- 结尾常有："切切"、"勿念"、"珍重"
- 玉简传讯可简练："某已知悉，速归。"

### 场景四：悟道/突破

- 心理描写集中爆发，可用单引号内心独白连发
- 天地异象按级别匹配（见表）
- 突破前往往有"回顾往昔"的闪回笔法
- 突破后往往有众人反应的侧面烘托

### 场景五：坊市交易

- 对话精炼，讨价还价有来有回
- 可穿插对丹药/法器/灵材的意象化描述
- 人物称谓用"道友"、"阁下"为主
- 灵石、丹药名称可加【】标注

## 高频语料库

### 状物四字词

**写景**：云海翻涌、霞光万道、月朗星稀、风雨如晦、烟波浩渺、层峦叠嶂、幽谷深潭

**写人**：仙风道骨、器宇不凡、飘逸出尘、面若冠玉、目若朗星、不怒自威、须发皆白

**写法术**：罡气翻涌、灵机荡漾、幽光闪烁、光华流转、煞气冲天、气机澎湃、剑光如虹

**写情绪**：古井无波、心念微动、默然良久、神色不变、微微一怔、心中凛然、面不改色

### 对话启句高频词

- 反问式："你……"、"你当真……"、"你以为……"
- 感叹式："好！"、"好一个……"、"好大的……"
- 确认式："正是。"、"不错。"、"此言……有理。"
- 迟疑式："这……"、默然片刻，"……"
- 冷笑式：冷哼一声，"……"、微微一笑，"……"

### 常用动词替换

| 现代词 | 玄鉴风词 |
|--------|----------|
| 看 | 望去、凝望、瞥见、抬眼看去 |
| 说 | 道、言道、开口道、低声道、沉声道 |
| 想 | 暗忖、思量、心中暗道、暗暗思量 |
| 走 | 徐行、掠去、御风而去、踱步 |
| 打（战斗） | 出手、交锋、对阵、动手 |
| 惊讶 | 一怔、神色微变、心中凛然 |
| 生气 | 面色一沉、冷哼一声、神色冷峻 |
| 害怕 | 心头一跳、脊背发凉、面露惧色 |

### 句式模板

1. **动作反应链**：`XX见了，顿时XX，XX道："……"`
2. **时间过渡**：`须臾` / `不过XX功夫` / `转瞬之间`
3. **听觉引入**：`只听得` / `隐隐约约听得` / `只听那`
4. **视角切换**：`却说` / `且说` / `再看那`
5. **场景收束**：`一时之间，……` / `一时间，……`
6. **对比转折**：`虽是……却……` / `看似……实则……`

## 禁止项

以下行为在润色中**严格禁止**：

1. **不改变原有人物姓名和核心设定**——姓名、道号、出身、境界不可改
2. **不改变情节走向**——谁生谁死、胜败结局、关键抉择不可改
3. **不改变关键对话中的核心信息**——传递的情报、承诺、威胁的内容实质不可改
4. **不在凡人角色口中使用修炼术语**——凡人只说人话
5. **不对白对话使用文言过度**——半文半白即可，不可达到古文观止程度
6. **不堆砌四字词**——每句最多 2 个四字词组，避免密集轰炸
7. **不滥用天地异象**——筑基以下战斗不配天地变色
8. **不把所有"说"都改成"道"**——可穿插"开口"、"出声"、"喝道"、"叹道"等变化
9. **不删除原文中的伏笔和暗示**——保持信息密度
10. **不在低级别场合使用高级别称谓**——筑基修士不称"本座"，胎息不称"老夫"

## 完整润色示例

### 原文（普通网文风格）

> 李寒走出洞府，看着外面的天空，心里想道：这次闭关花了一年时间，总算是突破到了筑基期。他感觉自己的实力比以前强了好几倍，要是再遇到那个仇家，一定能打赢。这时他的好友张铁柱跑了过来，高兴地说："老李，你终于出关了！"

### 轻度润色

只改标点、称谓、心理描写格式：

> 李寒走出洞府，抬眼望去，'这次闭关……一年光景，总算踏入筑基了。'他默默感受着体内气机，比之从前强了数倍不止，若再遇上那仇家，当可一战。
>
> 正思量间，一道人影掠来，却是好友张铁柱。那人满脸喜色，开口道："李兄，你可算出关了！"

### 中度润色

格式 + 句式节奏 + 对话风格：

> 李寒步出洞府，天光正亮。
>
> '一年了。'他抬眼望向远处山峦，心中暗暗计较——此番闭关，终是踏入了筑基之境。体内灵机翻涌，比之从前何止强了数倍？若是再遇上那人……'当有一战之力。'
>
> 正出神间，只听得一阵急促脚步声。张铁柱自山道那边奔来，人未到，声先至："李兄！你总算出来了！"
>
> 李寒微微颔首，并未多言。

### 重度改写（默认）

全面按玄鉴文风重写：

> 洞府的石门轰然洞开。
>
> 李寒自其中缓步而出，天光刺目，他微微眯眼。山风拂面，带着几分初秋的凉意。'一年了……'他立在洞口，望着远处层峦叠嶂，心中涌起一阵说不清的滋味。
>
> 此番闭关，终是踏入了筑基。
>
> 体内灵机如溪流般静静流淌，比之闭关前的滞涩，已是天壤之别。他默默握紧了袖中的拳头——那仇家若再来，断不会像上次那般狼狈了。
>
> "李兄——"
>
> 一道呼声自山道那边传来。李寒抬眼看去，只见张铁柱大步流星赶来，满脸都是喜色，到了近前一把抓住他手臂："你可算出关了！这一年，外头可发生了不少事。"
>
> 李寒嘴角微动，那张一向冷峻的脸上难得露出几分暖意："都还好？"
>
> "好，好得很！"张铁柱咧嘴笑道，"先不说这些，走，陪我喝两杯去！"

## 使用方式

用户使用 `/xuanjian-style` 或明确要求调用此技能时，按照以下规则执行：

1. **确认强度**：用户未指定强度时，默认执行**重度改写**
2. **严格走 4 步流程**：读原文→定策略→逐段改写→自校验
3. **保留原文的情节、人物和核心设定**，仅调整文风表达
4. **场景类型不明确时**，根据原文内容判断并标注
5. **输出时先简要说明做了哪些调整**（来自第二步的策略），再给出润色正文
