# 玄鉴仙族文风润色 Skill

基于季越人《玄鉴仙族》文风特征的 Claude Code 技能，将小说章节按玄鉴风格进行全面润色改写。

## 安装

```bash
cd your-project/.claude/skills/
git clone https://github.com/ximencuisu/xuanjian-style.git
```

## 使用

```
/xuanjian-style 请润色以下段落：
<你的小说文本>
```

也可指定强度（默认**重度改写**）：

```
/xuanjian-style 轻度润色：<文本>
/xuanjian-style 中度润色：<文本>
```

## 功能

- **三档强度**：轻度（格式规范）/ 中度（句式优化）/ 重度（全面重写）
- **4步执行流程**：读原文→定策略→逐段改写→自校验
- **7大文风维度**：语言风格、叙事结构、环境描写、句式节奏、特殊标点、人物塑造、战斗修炼
- **5种场景规则**：政治博弈、市井生活、书信玉简、悟道突破、坊市交易
- **高频语料库**：状物四字词、对话启句、动词替换表、句式模板
- **10条禁止项**：防止过度修改

## 关于《玄鉴仙族》

《玄鉴仙族》为季越人所著仙侠小说，以半文半白的古典笔法、对话驱动的叙事结构、冷静克制的情感表达著称。特色包括：

- 对话占比高（50%-70%），雅俗分级
- 心理描写以单引号 `'...'` 标注
- 功法/神通名用 `『』`，物品/丹药用 `【】`
- 短句密集，四字词组丰富
- 环境与人物心境高度同步
